## Serwis pożadanego stanu
Dynamiczna struktura danych opisujący pożądany stan systemu. Obejmuje  kontenery reprezentujące konfiguracje oraz liście reprezentujące intencje powiązane z dokumentami w trakcie ich procesowania. Kontenery są stosunkowo trwałe, podczas gdy liście znikają po osiągnięciu przez system pożądanego stanu.
