## Prosta szyna wysylania (1:n) i odbioru wiadomosci tesktowych 
Szyna opara o macierz publikator(domyslcie 32) X subskrybent (domyślnie 32)
Kazda wiamosci wysłana na wiersz publikatora (POST) może być nieznależnie odczytana przez subskrybenta (GET).
Pobranie widomosci przez subskrybenta jest jednorazowe.
Makymalny rozmiar widomości 1024 byte. Wiadomości są trwale zapisywane na dysk.
