## Minimalistyczny file object store
Store-srv - to częśc platformy robota kancelaryjnego Algorek, jest to prosta usługa składowania plików z interfejsem http. 
Usługa wykorzystywan jest bezpośrednio przez inne komemenety robota w bezpieczenej sieci. Usuga nie udostpęnia publicznego API.
Załaczana specyfiakcja (OpenAPI)[spec/openapi.yaml] ma tylko cel dukumentacyjny.
